In the app

Everything it does. Nothing more.

Five things to learn, and then you stop thinking about the app at all.

Your hotkey, your lock

Hold fn (the default) to talk, or switch to Right Option, Right Command, Right Control, or F13 in Settings…. Double-tap the hotkey to lock recording, or hold the hotkey + Space; tap again to finish.

Fast or Accurate

Pick Fast (Whisper small) for quicker results, or Accurate (distil-large-v3) for the original higher-quality model. Each downloads on demand. Inference never leaves this Mac.

Transcribe audio files

Choose Transcribe audio file… to pick or drop a wav, mp3, or m4a — no five-minute limit. Copy the result or save a .txt. File transcription stays raw and skips Write or Command.

Write & Command

Optional, on-device, off by default. Write cleans filler words and punctuation; Command rewrites selected text from a spoken instruction. Set a tone per app. Uses a local ~1 GB model, never the cloud.

One Settings window

The hotkey, Fast / Accurate, the optional writing model, and per-app tones all live in one place. The app can stay out of the Dock when you want it to.

Voice to caret

Three steps. No dashboard.

There is nothing between a thought and the place it belongs.

  1. 1

    Hold and speak

    Focus a supported editable field, then hold your hotkey — fn by default. The microphone is active only for the recording you start.

  2. 2

    Release to transcribe

    Your recording is turned into text by the local Fast or Accurate model, running entirely on this Mac.

  3. 3

    Text lands at your cursor

    The original app and exact field are verified again before insertion. If that check or insertion fails, the transcript is copied instead.

Press Esc during a recording to stop and delete that audio — nothing is transcribed.

Privacy, by architecture

Your voice doesn’t need a trip through someone else’s cloud.

A

Transcription stays local

After you download Fast or Accurate, inference runs on your Apple Silicon Mac. Switching models only downloads the one that is missing. The optional writing model is also local.

B

The microphone has a clear boundary

It opens only while you are recording and releases when the recording ends or is cancelled.

C

No account. No transcript archive.

Only the latest transcript persists locally for recovery until a newer result replaces it. The app does not build a transcript history.

Run it from source.

You need an Apple Silicon Mac with macOS 14 or newer, Python 3.11 to 3.13, and PortAudio. The first launch downloads the speech model you select. Accurate is the default; Fast is the quicker option.

  1. Install PortAudio with Homebrew.

    brew install portaudio

  2. Clone the repository.

    git clone https://github.com/Sdefendre/freevoicetranscribe.git
cd freevoicetranscribe

  3. Run the launcher. It creates a virtual environment, installs the pinned requirements, and starts the app.

    ./run.sh

  4. Follow the setup window: grant Microphone and Accessibility access, then download the selected local speech model. Open Settings… later for the hotkey, Fast / Accurate, the optional writing model, and per-app tones.

Full instructions, including manual setup and building the macOS app, are in the README on GitHub.

The practical questions

Before you start.

Does it need an internet connection?

Only to download the speech model you select, or the optional writing model if you use Write or Command. A second speech model downloads only if you switch and it is not already on disk. Once a model is on your Mac, work stays local.

How do I change the shortcut?

Open Settings… from the menu bar. The default is fn. You can switch to Right Option, Right Command, Right Control, or F13. Right-side modifiers may not work on keyboards that do not distinguish left and right keys. Double-tap the hotkey to lock recording; tap it again to finish.

What is the difference between Fast and Accurate?

Both run on this Mac through lightning-whisper-mlx. Accurate (distil-large-v3) is the default and the original higher-quality model. Fast uses Whisper small for a smaller download and quicker transcription. Each downloads on demand with a progress bar.

Can I transcribe an existing audio file?

Yes. Choose Transcribe audio file… from the menu bar, then pick or drop a wav, mp3, m4a, or similar file. There is no five-minute limit for files. Copy the result or save it as a .txt. The original file is not changed or uploaded. File transcription stays raw: Write and Command do not run on it. Live hold-to-talk recordings are still capped at five minutes.

What are Write and Command?

Both are optional, off by default, and stay on this Mac. Dictate is the default and never uses a writing model. Write cleans filler words, punctuation, capitalization, and spoken self-corrections. Command rewrites selected text from a spoken instruction. You can set a tone per app. They use a local ~1 GB model and never send text to a server. Cleanup applies to dictation only. Download the writing model from the same Settings… window that holds the hotkey and Fast / Accurate picker.

Which text fields are supported?

The field must be focused, enabled, and exposed by its app to macOS Accessibility as an editable value or text selection. Support can vary in apps that use custom editors or restrict paste behavior.

What happens if the original field cannot be verified?

The app fails closed: it does not type into a different field. It copies the transcript to the clipboard instead. If copying also fails, the latest transcript remains available from the menu bar.

Why does it need Accessibility permission?

macOS requires Accessibility permission for the global shortcut you choose, focused-field verification, and insertion into the supported editable field where you started.

What transcript data is stored?

Only the latest transcript persists locally for recovery until a newer transcript replaces it. There is no transcript history. Temporary recording audio is deleted after completion or cancellation. File transcription reads the file on this Mac and does not upload it.

What if I start recording by accident?

Press Esc. Recording stops and that temporary audio is deleted without transcription.

Does it run on Intel Macs?

No. FreeVoiceTranscribe currently requires a Mac with Apple Silicon and macOS 14 or newer.

Can I download it now?

Not as a packaged app yet. A public build still needs Developer ID distribution signing and Apple notarization. You can run it from source today; see Install from source.
